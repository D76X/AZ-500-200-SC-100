

# IS THERE A REPLACEMENT FOR AZ-500?

[Yes, the official replacement for the AZ-500 certification is the SC-500 exam](https://learn.microsoft.com/en-us/answers/questions/5953548/question-regarding-the-future-of-the-az-500-certif#:~:text=Microsoft%20is%20introducing%20Cloud,the%20transition%20period.), which earns you the Microsoft Certified: Cloud and AI Security Engineer Associate credential. [1, 2] 

Microsoft officially retired the AZ-500 exam and its associated Azure Security Engineer Associate certification on August 31, 2026. You can no longer register for, take, or renew the AZ-500 exam. [2, 3, 4] 
The transition to SC-500 is not a mere rebranding; it reflects a major structural shift toward securing modern, AI-first cloud architectures: [5, 6] 

* 
* What Carries Over (~80%): Core infrastructure security fundamentals remain. You will still be tested on identity and access management (Microsoft Entra), hybrid and multi-cloud platform protection, networking, storage, Azure Key Vault, Microsoft Defender for Cloud, and Microsoft Sentinel. [3, 7] 
* What is Added (AI & Deeper SecOps): SC-500 introduces a dedicated domain focused heavily on AI-workload security. This includes securing Microsoft Copilot, configuring Microsoft Entra Agent IDs, and using Defender for AI. Security operations tracking (like workspace automation, syslog collection, and Microsoft Purview auditing) has also been expanded. [3, 7] 
* What is Removed: Traditional network infrastructure components like Application Gateway, Azure Front Door, ExpressRoute encryption, and standard user-defined routes have been phased out of this specific track. [7] 
* 

If you already earned the AZ-500 certification before its retirement:

* 
* No Automatic Migration: Microsoft does not offer a transition exam or an automatic upgrade path to SC-500.
* Validity: Your Azure Security Engineer Associate certification will remain active and listed on your [Microsoft Learn Profile](https://learn.microsoft.com/) until its unique expiry date. Once it expires, it cannot be renewed and will move to your transcript's "Historical Certifications" section.
* Moving Forward: To maintain an active cloud security credential with Microsoft, you must sit for and pass the standalone [SC-500 exam](https://learn.microsoft.com/en-us/credentials/certifications/). [1, 2, 3, 8]
