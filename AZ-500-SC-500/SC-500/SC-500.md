Exam SC-500: Implementing End-to-End Security Controls for Cloud and AI Workloads 
is Microsoft's newest intermediate-level certification exam, replacing the retiring 
AZ-500.

## Exam Overview and Details

- Credential: 

Earns the Microsoft Certified: Cloud and AI Security Engineer Associate title.

- Replacement: 
Replaces the legacy AZ-500 exam, which fully retires on `August 31, 2026`.

- Duration: 
120 minutes.

- Passing Score: 700 / 1000.

- Scheduling: Available via `Pearson Vue`.

## Core Exam Domains

The exam tests your knowledge across four primary functional groups:Manage identity, access, and governance (20–25%): Securing Microsoft Entra ID, Azure Key Vault, Privileged Identity Management (PIM), and role-based access control (RBAC).Secure storage, databases, and networking (25–30%): Hardening storage accounts, configuring firewalls, network security groups (NSGs), and private endpoints.Secure compute (20–25%): Protecting virtual machines, Azure Kubernetes Service (AKS), containers, and app services.Manage and monitor security posture (20–25%): Utilizing Microsoft Defender for Cloud (CSPM/CWPP) and Microsoft Sentinel.New AI Security FocusUnlike the older AZ-500, SC-500 introduces modern requirements for protecting artificial intelligence workloads:Securing data and risk mitigation for Microsoft Copilot and AI apps using Microsoft Purview Data Security Posture Management (DSPM).Implementing conditional access and analyzing blast radius for Microsoft Entra Agent ID.Configuring guardrails and AI Gateways via Azure API Management and Microsoft Foundry.
