# Is the exam SC-5006 related to SC-500?

SC-5006 is a training course, not an exam, but it covers Microsoft Security Copilot topics that overlap with a portion of the 
[Exam SC-500](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-500) syllabus. [1, 2, 3] 

## Key Differences

* SC-5006: 

A 1-day beginner training course titled `Enhance Security Operations by Using Microsoft Security Copilot`. 
It does not have a dedicated certification exam attached to it.

* SC-500: 

The certification exam for the Microsoft Certified: Cloud and AI Security Engineer Associate credential. [1, 3, 4] 

## How They Relate

* Thematic Overlap: 

Exam SC-500 covers security posture, AI workloads, and tools like Microsoft Security Copilot and Security Copilot 
agents as part of its "Security Posture" and "Compute Security" domains. [2] 

* Preparation: 

Taking the SC-5006 training path helps build foundational knowledge regarding generative AI and Security Copilot 
functionality, which is a subset of the broader cloud and AI security skills measured on the SC-500 exam. [1, 2]
