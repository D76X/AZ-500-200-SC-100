# Have you evaluated the reliability and performance characteristics of utilized programming languages and frameworks?

Typically, the selection of programming languages and frameworks is driven by the availability of development skills or by the use of standardized technologies within an organization. However, for a mission-critical workload, it's essential to also evaluate the performance and reliability aspects of different languages and frameworks, as well as the capability differences within required Azure SDKs.


##  Options 01
The application uses multiple programming languages or frameworks to support distinct service requirements.
The availability of developer skillsets, or certain specific functional and non-functional requirements, might require specific programming languages or frameworks to be used to optimally build certain components.

##  Options 02
Extensive technology sprawl is avoided to prevent unnecessary operational complexity.
While autonomy around technology selection is strongly recommended for optimal service design, it's also advisable to prevent unnecessary sprawl with associated operational complexity by consolidating to a reasonable number of languages, SDKs, and services.

##  Options 03
All relevant Azure SDKs were evaluated to confirm the availability of required capabilities for selected programming languages.
Different Azure SDKs provide different capabilities and functionality, with certain languages providing a richer feature set than others.

##  Options 04
The .NET SDK is prioritized to access additional built-in reliability and performance features.
The .NET and Java Azure SDKs typically provide additional capabilities and receive new features first. There can be a delay in feature availability for other supported languages.

##  Options 05
None of the above.
