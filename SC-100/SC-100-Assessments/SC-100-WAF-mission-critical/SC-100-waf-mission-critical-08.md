# Is a serverless platform used to host application code?

Serverless computing provides compute resources on demand and eliminates the need to manage infrastructure altogether. The cloud provider automatically provisions, scales, and manages resources required to run deployed application code.

##  Options 01
Azure Functions are used for simple business process scenarios to provide a reliable application platform with near-zero friction development and operational experience.

Azure Function Apps can be used as a scalable platform for small and simple business processes to provide a reliable application platform that doesn't require the overhead of a full compute platform.

##  Options 02
For internal workloads, service endpoints or private endpoints are used to restrict access to private virtual networks.

On a serverless platform, like in any other scenario, network traffic should be restricted.

##  Options 03
Functions code is treated like any other code and subject to code scanning tools integrated with CI/CD pipelines.

The same quality gates and security measures should apply to functions code.

##  Options 04
None of the above.
